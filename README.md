# Mente Locale — Restaurant OS

App operativa per ristoranti: dashboard live, gestione tavoli, prenotazioni, KDS cucina, magazzino, HACCP e assistente IA.

## Stack
- Next.js 14
- Tailwind CSS
- Framer Motion

## Avvio locale
```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).
